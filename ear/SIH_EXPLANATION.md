
# Smart Crop Advisory System - SIH 2024 Solution

## Overview
This project is a comprehensive web interface designed for small and marginal farmers, providing AI-powered crop advisory, weather alerts, and market linkages.

## Key Features
- **Multimedia Home Page**: Uses a lightweight looped video to engage users emotionally with the concept of modern farming.
- **Optimized Performance**: Login and Registration pages use high-quality static images with lazy loading techniques implicitly handled by modern browsers to ensure fast load times on rural networks (2G/3G).
- **Accessibility**: High contrast UI, large buttons, and simple navigation for farmers with limited digital literacy.
- **Multilingual Ready**: UI structure supports easy localization (currently English, with dropdown for Hindi/Tamil/Telugu).

## Impact
- **Economic**: Helps farmers track market prices and reduce input costs through precise fertilizer recommendations.
- **Environmental**: Promotes sustainable practices by optimizing resource usage based on soil health.
- **Social**: Empowers marginalized communities with access to technology.

## Technical Stack
- **Frontend**: React (Vite) for fast performance and modular component architecture.
- **Styling**: Custom CSS for a unique, premium look without heavy framework overhead.
- **Routing**: Client-side routing for seamless navigation.
- **Icons**: Lucide-React for lightweight, scalable vector icons.

## How to Run
1. Navigate to the project directory.
2. Run `npm install` to install dependencies.
3. Run `npm run dev` to start the local development server.
